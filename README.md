# WARA – Empowering Women

Official website for WARA Empowering Women — a Pakistani women's clothing brand handcrafted by artisans from marginalized communities.

## 🌐 Live Site
Deployed on Vercel: [wara.pk](https://wara.vercel.app)

## 📁 Project Structure
```
wara-website/
├── index.html      # Full website (single page)
├── vercel.json     # Vercel deployment config
└── README.md
```

## 🚀 Deploy to Vercel
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → Import Project
3. Select this GitHub repo
4. Click Deploy — done!
